      操作说明与素材约定
      
镜头与对象朝向独立切换；图片、裁切和锚点编辑始终作用于“编辑素材”显示的方向。矩形转向保持当前画面上角的放置基准格：2×2 占地不移位，3×2 交换长宽；切换镜头不改变世界占地。不规则占地仍可编辑，暂不支持对象转向。鼠标位于画布且未编辑输入框时，按 R 转对象。

      
拖拽图片会调整当前素材的像素锚点，其他素材保持不变。适应画布只调整显示比例和位置，100% 按原始像素显示；镜头、对象朝向、视图比例和不透明度不写入导出的 JSON。

      
蓝色小框自动标记当前画面最上方占地格的格心，作为放置基准，无需手动选择。占地 JSON 记录基准朝向的格子坐标，调整列、行会重建矩形占地。拖拽图片或修改像素锚点可调整图片与占地的对齐；像素锚点可以在图片外。

      
类别记录用途，不改变图片外观。裁切和像素锚点分别编辑，锚点相对裁切左上角。要让裁切后保留的像素位置不变，裁切起点移动多少，锚点就减去多少。瓦片尺寸只用于预览，不写入元素定义。

      
每个方向可单独选图，也可用素材目录批量加载后绑定。单独选图以文件名作为相对引用，独立预览可重新选择这些图片；目录引用相对所选根目录。导出只生成 JSON，图片保持原文件。样本仍为演示标定。
