# 狗雕塑：P0-C 本地预览样本

`element.json` 是完整图片定义；`cropped.json` 是独立的裁切演示定义。页面加载并校验 JSON，不在页面脚本里硬编码占地或锚点。

`images/` 含从 `mylong/空闲娱乐设施和塑像/` 原样复制的 `sculpture_dog01.png`～`sculpture_dog04.png`。四张图片与 JSON 均作为 Demo 文件参与版本管理，无需另外从本机素材库复制。

需要通过 HTTP 服务打开 `element-preview.html`，以读取 JSON；使用 `npm run dev` 时地址为 `http://localhost:8033/demo/element-preview.html`。

## 演示标定与待核实项

- 四张原图尺寸分别为 158×110、158×110、158×126、158×125，运行时从实际加载结果读取。
- 图片 01/04/03/02 分别绑定 0/90/180/270 视图槽。2026-09-30 对照原作同一组已放置雕塑的城市旋转画面，确认原先 90°、270° 的图片绑定相反，已予以修正；180° 保留原配置，仍待独立画面补证。角度表示镜头方向，0° 以该对象显示图片 01 的视角为基准，不定义对象自身的罗盘朝向。
- 占地采用从 `[0,0]` 展开的 2×2，单元格尺寸按用户最新要求暂定为 80×40，保留手动校准。原点位于一个占地格中心，未把整个占地居中。
- 图片 01～04 的可见底座中心约为 `[79,69]`、`[79,69]`、`[79,85]`、`[79,84]`。按修正后的选图顺序，0/90/180/270 的锚点为 `[39,69]`、`[79,64]`、`[119,85]`、`[79,89]`。这些值由各图底座中心减去占地中心相对逻辑原点的投影偏移得到，仍是基于 80×40、2×2 占地的演示标定值，尚非原作引擎锚点读数。
- 原作按 R 改变对象朝向，与城市视角旋转分别取证。2026-10-04 根据用户矩形建筑实验修正放置计算：转向后仍对齐当前画面最上角占地格。旧 JSON 的原点/anchor 保留为素材标定坐标；`resolveElementPlacement()` 换算定义原点的世界位置，绘制按镜头与对象合成角度选槽，使图片和 2×2 占地共同保持落位。本轮不重新猜测或修改这组 anchor；它们仍是演示标定值。
