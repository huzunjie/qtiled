# 狗雕塑：P0-C 本地预览样本

`element.json` 是完整图片定义；`cropped.json` 是独立的裁切演示定义。页面加载并校验 JSON，不在页面脚本里硬编码占地或锚点。

`images/` 含从 `mylong/空闲娱乐设施和塑像/` 原样复制的 `sculpture_dog01.png`～`sculpture_dog04.png`。四张图片与 JSON 均作为 Demo 文件参与版本管理，无需另外从本机素材库复制。

需要通过 HTTP 服务打开 `element-preview.html`，以读取 JSON；使用 `npm run dev` 时地址为 `http://localhost:8033/demo/element-preview.html`。

## 演示标定与待核实项

- 四张原图尺寸分别为 158×110、158×110、158×126、158×125，运行时从实际加载结果读取。
- 人工配置 01～04 对应 0/90/180/270 槽；这是当前演示绑定，不代表已核实的原作罗盘对应，也不是运行时按编号自动推断。
- 占地采用从 `[0,0]` 展开的 2×2，演示瓦片尺寸为 80×40。原点位于一个占地格中心，未把整个占地居中。
- 可见底座中心约为 `[79,69]`、`[79,69]`、`[79,85]`、`[79,84]`。据此设置各向锚点 `[39,69]`、`[79,49]`、`[119,85]`、`[79,104]`，让四向的逻辑占地与底座大致对齐。这是视觉演示值，不能据图片外框证明原作步长、占地或朝向。
- 裁切示例将左侧切去 20px、上侧切去 10px，宽度改为 118px、高度减 20px；锚点同步减去 `[20,10]`，使剩余像素保持原落位。原图没有被改写。

P0-D 将提供参数编辑。此处只验证同一份定义能驱动四向显示、裁切和锚点定位。
