# 原作整级高程素材

地图编辑器与元素工具共用 `elements.json` 的完整原图、裁切和锚点；`rules.json` 负责场景高差到素材选择。单个元素自身四向共用图片，场景规则按四向选不同元素，二者职责不同。

来源：`China_Elevation.sg3` 的图201–232（组0x202e–0x204d），包含普通 E2、一二级过渡及 E1 共32张完整原图。原图78px宽，底菱形中心锚点 `[39,height-20]`；80×40单元每级升40px。原12张E1定义及其图集位置不变，新增20张放在图集下部。低格画坡，高格画升高后的普通地表。

工具支持0～16整级高度，形态取决于相邻高差；保留147行顺序和四向列 `[1,0,3,2]`，按旋转后的同一邻域检查方向一致性，不放行原表的已知方向反例。只读解析不改高度；笔刷使用已证局部修整规则，重复扫描、循环检测和上限属于工具事务策略，不声称等同原作整笔调度。一次大幅设高可能失败，建议逐级塑形。水陆高差/坡面直接贴水、实体地基、角形半坡、复杂坡道和角色通行仍受限制。

`contexts.json` 指向共用多级地图中的四个样例，供元素工具只读预览世界邻域的四向结果；它不另存一份形态到图片的映射，也不代表完整地形资产编辑/导出已完成。

## 三档气候地表

可选地图字段 `climate` 为 `arid`、`temperate`、`humid`；省略保留原有地表。只按真实水格推导普通草地，空角/界外不作为湿润来源。草地五档各九张、档内固定外观；干旱使用土坡，另两档沿用原坡面。强度/档位/图片不写入地图，未包含树木和资源修正。

草地 `China_Terrain` 202～246、干旱坡面 `China_Elevation_Dirt` 201～232 均逐张匹配并复用 mylong PNG，原尺寸/透明度不变；新增独立图集，既有图集及定义不变。

## 一级直边坡道与半坡

两套新增 `slope-features[-dirt]-atlas.webp` 各56张，均将原作 SG 记录与 mylong PNG 的 RGB555颜色、alpha、尺寸逐张匹配后直接复用，不缩放、不垫地表。记录233～240为普通坡道及道路，269～292为直边半坡/坡道/道路双部件，301～324为端部过渡和孤立半坡。每个部件使用原图底面中心 `[39,height-20]`，逐格参与画序和alpha拾取；既有图集及锚点不变。

作者事实为主格可选 `ramp: true`、`halfSlope: true`，省略表示没有。只支持原表67～74对应的一级直边；半坡向世界低侧延伸一格，两格高度仍为整数，不保存副格标记、选图、镜头或通行结果。孤立、单侧、连续直边由原作0x476290/0x4772f0分支选图。点击任一半坡部件操作整体；道路仅允许沿坡道高低两端衔接，半坡整体铺擦道路，使用专用坡道路图。

工具保守约束：水域、空角/界外、实体或其他坡面占用副格时拒绝；改变占地/移除承路坡道前先擦路。后续高程/地表编辑破坏坡面则整笔失败，不调整既有联动算法。角形半坡、复杂交汇、道路等级与角色通行未纳入此批。原作依据为手册和静态程序/数据，非原作运行验收。

对应样本为 `demo/static/map-samples/slope-features-map.json`。
