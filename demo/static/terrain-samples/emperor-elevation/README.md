# 原作整级高程素材

地图编辑器与元素工具共用 `elements.json` 的完整原图、裁切和锚点；`rules.json` 负责场景高差到素材选择。单个元素自身四向共用图片，场景规则按四向选不同元素，二者职责不同。

来源：`China_Elevation.sg3` 的图201–232（组0x202e–0x204d），包含普通 E2、一二级过渡及 E1 共32张完整原图。原图78px宽，底菱形中心锚点 `[39,height-20]`；80×40单元每级升40px。原12张E1定义及其图集位置不变，新增20张放在图集下部。低格画坡，高格画升高后的普通地表。

工具支持0～16整级高度，形态取决于相邻高差；保留147行顺序和四向列 `[1,0,3,2]`，按旋转后的同一邻域检查方向一致性，不放行原表的已知方向反例。只读解析不改高度；笔刷使用已证局部修整规则，重复扫描、循环检测和上限属于工具事务策略，不声称等同原作整笔调度。一次大幅设高可能失败，建议逐级塑形。水陆高差/坡面直接贴水、实体地基、半坡、坡道、其他主题和角色通行仍受限制。

`contexts.json` 指向共用多级地图中的四个样例，供元素工具只读预览世界邻域的四向结果；它不另存一份形态到图片的映射，也不代表完整地形资产编辑/导出已完成。

取证、指纹、完整像素解码、方向正反例和源文件归档见 [evidence/review.md](../../../../output/emperor/elevation-edit-implementation-2026-10-10/evidence/review.md)。
