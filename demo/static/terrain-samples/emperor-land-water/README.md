# 普通陆地与水域素材样本

此目录供元素编辑器和地图 Demo 读取同一套原作素材、动画定义与规则数据。`elements.json` 按元素 ID 索引；`rules.json` 提供普通平地水岸的 46 行邻域表及三个动画元素引用；`water-shore-atlas.png`（624×1140）包含 **145 张原作图片**，由 RGB555 原值与原透明信息解码，不缩放或重绘。

- `emperor-bare-land` 及 `-1`～`-3`：普通陆地与道路底图，来自用户提供的 `干枯的黄土地/China_land1_00047.png`～`00050.png`。无缩放打包为 `bare-land-atlas.png`，按世界格坐标稳定散布四种外观；`terrainVariant` 可固定选择。刷新、四镜头与 JSON 回读保持一致，不新增环境规则。
- `emperor-grass-202`～`emperor-grass-246`：五档草地，各九种外观，共用`grass-atlas.png`。
- `emperor-tree-927`～`emperor-tree-971`：18张普通树、18张竹类、9张共用残株外观，共用`trees-atlas.png`（720×486）。占地均为单格，图片尺寸不决定占地。
- `emperor-rock-458`～`471`、`472`～`485`、`486`～`499`：普通石、铜矿、铁矿各14张，分别8张1×1、4张2×2、2张3×3，共用`rocks-atlas.png`（1120×636）。逻辑占地取原作组合分支，不由图片宽度推断；四向共用图片，逐向锚点对齐整个底面。
- `emperor-terrain-202`：保留原带草陆地样本，兼容已有素材引用。
- `emperor-terrain-386`～`emperor-terrain-457`：原普通水岸组的全部 72 张图片。
- `emperor-terrain-664`～`emperor-terrain-735`：水面动画所需的全部 72 张原图，单图定义保留供素材检查。

Demo的植被与岩石类别、素材池与图集加载清单统一由[`terrain-sample.js`](../../js/terrain-sample.js)维护；这是样本消费配置，不属于基础库API。

元素库共 **284 项定义**：281 项 v1 静态单图，以及共用上述图集的 3 项 v2 动画。每个动画的 `sequences.water` 都有 24 帧，四向显式引用同一序列，各向锚点仍独立。

| 动画元素 | 原图帧序 | 普通场景中的用途 |
|---|---|---|
| `emperor-water-even` | 664、666、…、710 | 普通内部水面，以及偶数外观字节的内部过渡 |
| `emperor-water-odd` | 665、667、…、711 | 奇数外观字节的内部过渡 |
| `emperor-water-deep` | 712、713、…、735 | 宽阔水域的深处 |

不能把 #664～711 按连续编号播成 48 帧。三个动画均明确设置 `frameDurationMs: 100`、`timingSource: "author"`：**100ms 是本样本作者选择的预览时长**，不是推断出的原作固定帧率。实际播放时间由页面时钟传入，不写入定义或地图。

邻域顺序和条件含义记录在规则中；条件 0 为水、1 为非水、2 为任意。QTiled 的 0、90、180、270 度对应原表列 `[1,0,3,2]`。完整图像高度为 40～58，不能统一裁成 40；锚点 `[39,height-20]` 为工具明确采用的底部菱形中心。

普通水面、过渡和深处由陆/水布局派生，不新增作者填写的水深字段。规则先检查 3×3 水域，再执行原作对应的形态修整；保留下来的内部标记还须八邻全为标记，才使用 deep 帧族。有陆地包边的 3×3 水池只有普通内部水面，4×4 水池有过渡，5×5 水池才出现中央一格深处。固定外观输入来自已有 `terrainVariant` 或工具的世界坐标哈希，初始相位不因镜头、反复预览或 JSON 存读重新抽取。

本样本的 deep 表示常态水域的派生外观，不表示数值水深或洪水模拟。

水岸邻域匹配将界外及 `null` 格视为水侧，但它们不作为实际水源，也不绘制或修改。本规则包不包含 BEACH、rim、洪水模拟；高程与网络由其他 Demo 规则处理。缺少动画元素或不支持的输入会拒绝整笔候选，不退回静态图掩盖缺失。

素材来自《皇帝：龙之崛起》的 `China_Terrain.sg3` 及已有PNG，权利归原作品权利人所有。示例素材的使用不改变其权属；运行Demo不需要携带原程序。

## 三档气候地表（2026-10-12）

可选地图字段 `climate` 为 `arid`、`temperate`、`humid`；省略保留原有地表。按真实水格及树木/残株推导环境强度；空角/界外不作为来源。草地五档各九张、档内固定外观；干旱使用土坡，另两档沿用原坡面。强度/档位/图片不写入地图；树木和残株共用50起、四邻每步减10的传播，较强来源阻止覆盖。未包含肥力生产或其他资源修正。

树木类别由`cell.tree`保存，支持普通树、竹类及各自静态残株。成熟普通树和竹各有外围/包围两组9图，残株共用一组9图，组内稳定选择；这是本工具的创作规则。绘制资格、冲突、清除与存读见[地图工具说明](../../../../docs/map-definition.md#成熟树木与竹类)。不模拟生长、砍伐或恢复计时。

`water-shore-atlas.png` 原名 `atlas.png`；更名不改变图片字节或裁切。其中除水域和岸线外，保留既有兼容陆地帧202。岩石的占地、冲突、历史及存读见[岩石与矿物](../../../../docs/map-definition.md#岩石与矿物)。

## 静态采石地

地图格以 `quarry: true` 保存采石范围；不存在时省略字段。地图编辑器使用独立“采石地”按钮，固定6×6世界格足迹（x=-3..2、y=-2..3），允许相邻/重叠扩展；Ctrl落笔清除该足迹，通用清除可逐格移除。整笔预览、取消、撤销/重做及JSON存读复用现有地图事务。不包含可采数量、开采进度、生产或湿度羽化。

`quarry-atlas.png`包含原China_Terrain.sg3记录972..977、1006..1125，以及外圈回退使用的247..254，共134张。每格单独派生图像，不创建6×6父实体。原包SHA-256为`56e9fe6bbbbdc93d28f44883bd9bd8f9cfe0198f024a5af1e4589d47319f374d`。图集留透明间隔，槽高48px容纳46px高的第253号过渡图。

`quarry-rules.js`采用原程序0x837e70/0x8380f0规则表、0x543e20的静态几何分支及现有镜头列映射[1,0,3,2]。变体由已存terrainVariant或稳定世界坐标字节决定，镜头转动不改变事实。只接受等高平地，与树木、岩石矿物、道路、实体和坡面互斥。原表无法匹配的零碎轮廓会在导入/提交时拒绝并提示；这是工具的保护规则，不代表原作也采用相同拒绝行为。

本地可复跑补证、打包和像素映射在`output/emperor/quarry-editing-scope-2026-10-13/`；原作手册规则、静态代码证据与Demo验收分别记录，不把静态分析当作原游戏运行验证。
