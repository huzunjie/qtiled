# 普通道路与静态民居样本

来源：本机原作 China_Terrain.sg3/.555 的 782～799（R4 普通道路图组），China_General.sg3/.555 的 1515/1516（完整 2×2 静态住宅图）。仅解码、裁切打包，不重绘图片。

道路表提取自原作普通道路邻接表，只输入普通道路四邻连接；特殊道路/桥/墙/坡道标记不在此消费。镜头列 `[1,0,3,2]` 沿用已校准的 QTiled 世界方向。变体按世界坐标稳定选择，边界外为无道路。

民居 2×2 底面由 SG type=30、flags[3]=2、uncompressedLength=12800 及完整底面像素确认；用现有矩形上角格定位。两个图作为 Demo 作者配置的两向外观，0°/180° 共用 1515，90°/270° 共用 1516，各自锚点按旋转后的底面计算。这不是原作四向外观/门口/经营规则的还原。未采用需拼装的行政建筑 1904～1907。

地图事实：`cell.road = "ordinary"` 表示普通道路；无道路省略该字段。地表仍为 land。民居使用独立 entity，不写到 cell；地基需全在等高、无坡面的陆地上，不与道路、实体重叠。既有装饰之间的共存策略保留。地图、历史和编辑均不保存派生道路图片。

普通道路单图替换地表，不叠加草地或黄土地。78×40 道路锚点为 [39,20]，与已有地表的菱形底面对齐；旧归档提取脚本 height-21 得到的 [39,19] 会下移 1px，已更正配置。素材像素、裁切和道路连接表保持不变。

## 四款住宅围墙与门洞

四款图组起点依次为 370、387、404、421（SPR_RES_WALLS1～4）。每款前 13 张为墙段，偏移 13/14 为两个完整门图；偏移 15/16 是供动态对象穿门时使用的前景片，当前静态场景无需重复叠加。`residential-wall-atlas.webp` 保留四款共 60 张完整原图，第一款原有裁切位置不变，另外三款向下追加。无损 exact WebP 与原图完整 RGBA（含透明 RGB）一致。来源指纹、原图和提取/核对脚本保留在本地 output/emperor/residential-walls-four-2026-10-16/。

墙段四邻选图来自 EmperorEdit.dat 的 0x805bf0 专用表，门朝向来自 0x415040。四款墙和门均参与邻接，本格按自己的款式选图；四镜头仅换图，变体沿用 Demo 世界坐标稳定选择。单格锚点为 [39, height - 20]；完整门图包括地面，不另叠道路图。

地图保存 `cell.residentialWall = "wall-1"`～`"wall-4"` 或 `"gate-1"`～`"gate-4"`，缺省无墙门；首片的 wall-1/gate-1 文件直接兼容。道路与门独立保存：先路后墙生成同款门；先墙后路拒绝，墙两侧修路不会转门。清除门只拆门，下一笔才可清路。平坦陆地及草地可建，树木和其他地物、实体拒绝，需先清除。同款重画不变；异款覆盖拒绝，先拆旧墙门后再建。

放置、组映射和混合邻接有本地程序依据；先墙后路、删除顺序按用户明确规则；同款重复无变化沿用编辑器惯例。显式陆水或高程编辑按最终地形清理失效墙门，历史、JSON 保存与读取保留款式和墙门身份。


## 城墙、城门与塔楼

`city-wall-map.json` 包含城门、相连城墙和一座塔楼；塔楼占地内原墙已消耗，右侧墙段保留，可继续演示放塔与拆除。

城墙使用 `cell.cityWall = true`，城门使用 `city-gate` 实体，完整占地 5×3（可转向）。平坦陆地不限制绝对高程，半坡和坡道不可建；城墙不能覆盖道路、住宅墙、树木及其他实体。城门要求中间三格直路、道路两侧各两格墙、其余八格为空地。建门消耗四格墙；拆门保留三格道路，不恢复墙。

城墙选图使用原作八邻域表，门和塔占地参与连接；直段成对外观按世界格稳定交替，不复制原作刷新次序状态。放置前拒绝补齐实心2×2墙块；导入非法密集墙块也明确拒绝。

塔楼为独立按钮，使用 `city-tower` 实体、固定2×2世界占地。建塔至少覆盖一格城墙，消耗占地内城墙，不覆盖道路、住宅墙、树木或实体；逐格沿用原作密集墙角资格检查。拆塔不恢复原墙，保留占地外城墙与道路。879主体、880～885垛口和886～887门使用原素材；依据四向邻接隐藏连接处垛口、显示前侧门，绘制顺序为主体、后垛、门、前垛。未实现人员或战斗插层。

城门保留原作 888～917 的十五格分片布局，按每格深度分别绘制、参与透明命中，完整实体占用用于选择和拆除。四镜头映射到原作列 `[1,0,3,2]`，在固定逻辑占地上分别使用 `917-i、888+i、903+i、902-i`。78×40 底面沿用 `[39,height-20]` 锚点。`city-wall-atlas.webp` 包含城门30张、城墙18张及塔楼9张原图，无损 exact 编码，完整 RGBA 与原始解码一致。未引入战斗、人员或可达性模拟。

场景排序须同时保证完整占地地表先于主体、邻近物体前后遮挡正确、透明命中与实际画序一致。整体实体沿用完整占地最前端排序；城门按单格部件排序；塔楼按占地中心排序，并提前绘制其占地地表。调整实体画序时，须同时检查四个镜头的地基与邻接接缝，不能只检查实体内部部件次序，也不能把所有地表统一压到最底层。
