# 游戏编辑器与资源迁移

元素编辑器、素材预览、地图编辑器和后续游戏实例由独立项目 `emk.pyzy.net` 继续维护：

- [元素编辑器](https://emk.pyzy.net/element-editor.html)
- [地图编辑器](https://emk.pyzy.net/map-editor.html)

QTiled Demo 导航保留上述外部入口。本仓库已移除原元素编辑／预览、地图编辑、水域动画页面，以及专属脚本、样式、光标、图集、元素定义、地图样本和业务测试。

## 项目职责

| QTiled | EMK |
| --- | --- |
| 基础图形、坐标换算、选区与寻路 | 编辑器页面、交互、历史与文件工作流 |
| 元素定义、通用编辑与校验、动画帧解析 | 素材集合、图集、原作地表和构筑物规则 |
| 地图数据、占用与实体消费 | 场景组织、地图编辑及后续游戏运行能力 |
| 四向投影、图片加载与 SpriteJS 适配 | 龙之崛起调研、素材来源、游戏进展与待办 |
| 几何、海拔、寻路与四向视图 Demo | 元素与地图编辑器的浏览器验收和业务回归 |

通用源码、对应测试及正式可选 UMD 构建继续保留。开发和 Demo 发布只生成保留页面使用的核心与四向视图包；`npm run optional` 仍生成地图、视图和元素渲染三份正式 UMD。

## 调研与历史

EMK 已保留龙之崛起调研、证据、进展及历史浏览器记录。后续请从该项目的 `README.md`、研发归档及最新交付记录续接；旧记录中的 QTiled 页面路径和发布地址仅表示历史状态。

旧 Demo 的业务测试随其实现退出 QTiled 测试集，不能将测试数量减少解释为同等覆盖已在 EMK 重建。EMK 当前的数据格式和页面结构已有调整，专项用例需结合新接口选择性移植。

Demo 发布使用 `output/demo-release/`，线上旧编辑器页面及专属资源按退役清单定向清理；保留基础 Demo、公共资源和核心／四向视图发布包。
