# P0-D：静态元素编辑与独立回读

[元素编辑器](../demo/element-editor.html) 复用 P0-A 的校验与导入、P0-B 的坐标变换以及 P0-C 的图片加载和绘制。不向核心入口增加 DOM、图片或 SpriteJS 依赖。

## 编辑与导出接口

两个函数由纯数据入口 `src/elements` 导出，也由浏览器可选入口 `src/element-preview` 转出。

```js
import { applyElementEdit, exportElementDefinition } from '../src/elements';

const edited = applyElementEdit(definition, {
  field: 'anchor', angle: 90, value: [59, 39],
});
const { json, issues } = exportElementDefinition(edited, sourceInfo);
```

| 操作 | 输入约定 | 结果 |
|---|---|---|
| `applyElementEdit` 修改占地 | `{ field: 'footprint', value: [[0,0],[-1,0]] }` | 替换逻辑偏移，不旋转、排序或重新居中 |
| `applyElementEdit` 修改视图 | `{ field: 'source'/'rect'/'anchor', angle: 0/90/180/270, value }` | 只改所选方向的一个字段，不补其他方向 |
| `exportElementDefinition` | 定义和实际 `sourceInfo` | 成功返回 `{json, issues:[]}`；失败返回 `{json:null, issues}` |

编辑函数不改变输入，复制被修改的对象路径及传入数组；未修改分支共享引用，调用方继续按不可变数据使用。调用方提供具有 `views` 对象的定义或草稿；不支持的编辑字段抛出 `TypeError`，非法角度抛出 `RangeError`。字段值可以暂时非法，例如越界裁切或空占地，由现有 `validateElementDefinition` 报告，而不是静默修复。

导出前复用完整校验，缺向、缺图片、非法占地、越界裁切均不能正式导出。JSON 使用两空格缩进并保留结尾换行，不改变相对图片引用，不嵌入图片。ID、类别等普通控件赋值留在工具内部。

## 使用闭环

1. 运行 `npm run debug` 生成 Demo 包，通过 HTTP 打开编辑器。使用 `npm run dev` 时地址为 `http://localhost:8033/demo/element-editor.html`。
2. 默认载入狗雕塑样本。新建时先设置占地列、行，再点击“新建定义”；同时清空上一份已加载素材及文件选择状态，图片候选仅保留“请选择图片”，需要重新选图或载入素材目录。网格直接显示坐标和矩形占地；通过“点选原点”在占地中选择一个格子作为 `[0,0]`。调整列、行会实时重建矩形占地。
3. 右侧方向按钮与图片配置放在一起。每个方向可以单独选文件，也可选择素材目录批量载入后从下拉框绑定。单独选图后以整图作为初始裁切范围，仍保留当前像素锚点供调整；不自动给其他方向补图。ID 默认 `new-element`，保存前应改成稳定、可区分的名称。类别只记录地块或精灵用途，不改变图片外观。
4. 裁切和像素锚点分别输入；裁切标题旁的“重置”恢复整图裁切范围，不改锚点或占地。当前方向已配置时即可预览，其他方向可稍后补齐；正式导出仍检查完整四向。预览始终走 `resolveElementDraw` → `renderElementPreview`。
5. “网格操作”可选查看坐标、增删占地或点选原点；也可输入占用格子 JSON。点击使用 `getPointerPosition` → `pickGrid`。重选原点会把所有偏移减去所选格，并按四个方向分别换算像素锚点，保持图片与占地的相对位置；切换方向本身不改数据。删除到空集合时禁止导出，仍可点击添加。
6. 校验通过后点击“导出 JSON”，先查看只读配置预览；可返回继续编辑，或点击“下载 JSON”下载所看到的这份配置。关闭编辑页，在[独立预览](../demo/element-preview.html)重新选择图片文件或素材根目录，再导入下载的 JSON，检查四向结果。使用狗雕塑样本时，可使用预览页自行加载的内置图片。

目录选择器将所选目录名之后的路径作为素材键。例如选择 `dog/`，其中 `images/sculpture_dog01.png` 对应定义中的同名引用。共用的 `demo/static/js/element-files.js` 只做 File 集合到相对路径索引的转换；两页分别加载图片和配置，不使用 localStorage、编辑器内存、跨页消息或隐藏服务。

单独选图以原文件名作为相对引用，独立预览可选择多个图片文件。已加载的同名文件不能被另一个文件静默覆盖；复用同图用下拉框，不同图同名时需先区分文件名。文件输入只在本机页面读取，不向服务器上传图片。

## 编辑反馈与边界

草稿显示四向完成数与配置问题。缺少其他方向不影响已配置方向的预览；当前方向的裁切、图片引用或占地非法时清除图片，坐标网格与合法占地覆盖保留，正式导出禁用。有配置问题时直接显示完整列表，不折叠。导入使用 P0-A 契约，非法文件不替换当前草稿。文件加载时暂时关闭文件和参数输入，避免较早的加载结果覆盖后来的编辑。

页面启动时检查运行包是否提供编辑和导出函数，旧包会明确提示重新构建，避免控件显示正常但执行失败。

信息和参数栏始终位于画布右侧，沿用 `preview-workspace.css`。编辑器与独立预览均根据四向素材和占地范围适配显示，保留原始绘制参数。

编辑网格至少显示 9×9，并根据占地的最小/最大整数偏移向外多留两格。修改占地行列、占地 JSON 或点选原点后重新计算；四向投影共用最大包围范围，连同已配置的四向图片边界决定“适应画布”的比例和位置。切换方向沿用同一个最大范围，避免长条占地因切向超出画面。该计算只调整编辑视图，不推断图片底座、真实占地或像素锚点。

“适应画布”按实际可见宽度缩小并居中图片与网格；“100%”按原始像素显示，画布按四向网格及图片的完整范围撑开，留出边距，由外层容器横向/纵向滚动查看。工具栏不随画布滚走。素材加载、方向切换、参数及窗口尺寸变化后重新计算。视图变换发生在显示层，点击位置先通过 `getPointerPosition` 读取滚动后的画布位置，再逆变换为原来的投影像素坐标。坐标文字不绘制背景。

在图片矩形内按住主按钮拖动，按当前显示比例把屏幕位移换算为像素锚点的反向变化，并实时更新当前方向的锚点输入。短距离按下抬起仍执行网格单击操作；完成拖拽不会再次触发占地增删或原点选择。取消拖拽恢复起始锚点。拖拽过程中不自动重算视图，以免图片追随鼠标时画面跳动；需要重新居中时点击“适应画布”。

“底边吸附”默认开启：从当前裁切内读取 alpha ≥ 128 的可见下缘，识别与网格同斜率且有连续像素支撑的斜边，拖近任意网格边线约六个屏幕像素时吸附。吸附时显示绿色辅助线，按住 Alt 或关闭开关可自由拖动。读取失败或没有可靠斜边时保持自由拖动并提示；这不是自动识别建筑底座，复杂阴影、异形轮廓仍需人工校准。只调整当前方向锚点，不改变占地、其他方向或原图；仍保留小数精度，不将全部锚点强制取整。

网格操作状态悬浮于画布可见区域左下角，滚动时位置保持不变且不拦截鼠标；右侧标题只显示“元素参数”。

“不透明度”调整图片预览组（含裁切边框），网格、占地和原点覆盖保持清晰。视图比例、视图位置和不透明度不进入元素定义或导出的 JSON；拖拽调整的像素锚点正常保存。

顶部只保留文件操作。占地行列和 JSON 归右侧“元素参数”，预览尺寸直接显示，不再使用高级折叠区。网格操作位于画布工具栏，数值名称紧靠输入框，文件选择显示为紧凑按钮，长说明单独折叠。

占地提示紧跟标题，JSON 默认单行，可手动拉高。画布工具栏分为视图、居中的网格操作、不透明度三组；左侧预览区高度不小于右侧参数栏，适配计算使用实际可见宽高，100% 模式仍由画布外层滚动。

导入和修改占地后，行列同步其外接范围；自定义形状会明确提示修改行列将重建矩形。非法行列输入未应用时禁止导出，避免导出与可见输入不一致。文件操作失败可清除该次操作的提示，继续编辑已有定义；实际定义的校验问题不能通过此按钮消除。

瓦片尺寸属于视图参数，不写入元素定义；编辑器和独立预览默认均暂定为 80×40，初始化直接读取表单，保留手动调整，回读时需保持一致。编辑画布工具条分别显示逻辑尺寸与视图比例，缩放会改变屏幕上看到的大小，不改变逻辑的 80×40。四向素材绑定与样本锚点仍为演示标定，原作方向、真实占地和步长继续待核实。

本片不编辑原始像素，不包含 GIF、地图笔刷、地图放置或经营规则。正式可选包与 npm 子路径仍属于后续打包工作。
